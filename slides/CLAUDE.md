# CLAUDE.md for `slides/`

Marp decks, one per session: `YYYY-MM-DD.md` builds to `YYYY-MM-DD.pdf`. Build one with
`yarn build:day 2026-08-03`. See the root `CLAUDE.md` for writing conventions and
`../README.md` for the diagram and build workflow.

## Frontmatter and title

Copy a recent deck (for example `2026-08-03.md`) for the exact header and footer format:

- `description: "Week N, Day M"` (or a phase label like `"Capstone: Kickoff"`)
- `footer: "YYYY-MM-DD · Week N: Theme"`
- A lead title slide using `<!-- _class: lead -->` and a `## {topic}` line, then Agenda.

## The `---` seam trap (important)

Slides are separated by `---` alone on a line. If a text line sits **directly above** a
`---` with no blank line between them, Marp reads the `---` as a setext H2 underline and
**merges the two slides**. Always keep a blank line before every `---`.

Check seams after editing (line 9 is the frontmatter close; anything else printed is a
merged seam to fix):

```bash
awk 'prev!="" && $0=="---" {print NR} {prev=$0}' slides/YYYY-MM-DD.md | grep -v "^9$"
```

## Diagrams: reference external files, never inline

Inline `<svg>` does **not** render in the PDF. Put the image in `slides/diagrams/` and
reference it: `![Alt h:360](diagrams/name.svg)`.

- Most diagrams are Mermaid: author `diagrams/name.mmd`, which renders to `name.svg` at
  build time.
- Some are generated by scripts (matplotlib, seaborn) or drawn elsewhere and committed as
  `.svg` directly, with no `.mmd`. Both are fine; `build-diagrams.sh` only errors when
  neither a `.mmd` nor a `.svg` exists.

## Two-column layout

Requires `html: true` (already set in `../marp.config.js`). Define the style once, then
use divs with blank lines around the inner markdown so it renders:

```html
<style>.cols { display: grid; grid-template-columns: 1fr 1fr; gap: 1.5rem; }</style>

<div class="cols"><div>

left column markdown

</div><div>

right column markdown

</div></div>
```

## Sizing

Slides are 1280x720. Watch for content running off the bottom, or a line wrapping by a
single word; trim the wording or lower an image's `h:` height. Jon verifies the rendered
PDF himself, so hand off borderline layout for a human look.
