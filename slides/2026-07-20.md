# Follow Up: Does Adding Irrelevant Features Affect the Model?

Yes, though not in the way the score suggests.

- Adding a feature **never lowers** R-squared, even a column of pure random noise
- Each new feature is another **knob** the model can turn to chase a fake pattern
- The score rises while the model gets **worse** at anything new: this is **overfitting**
- Give it as many knobs as rows and it fits **every point**: a perfect score, nothing learned

**A perfect R-squared is a warning, not an achievement.**

# Hold Some Rows Back

If the score only ever rises, how do we tell a real model from a memorizer?

- You would not test a student on the exact questions they studied
- Scoring a model on the rows it trained on is an **open book exam**
- So **split** the data before training: keep most of it, hold the rest back
- **Train** on the rows you kept; **test** on the rows the model never saw

Predicting rent from **`size_sqft`** alone: train R-squared **0.769**, test R-squared **0.703**.

---

# train_test_split

```python
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=0)       # hold back 20% of the rows

model = LinearRegression().fit(X_train, y_train)   # learn here
model.score(X_test, y_test)                        # grade there
```

- `test_size=0.2`: keep **20 percent** of the rows back for testing
- `random_state=0`: the same split every run, so results are **reproducible**
- Never let the model see `X_test` until you score

Fit on **train**. Report the **test** number.

# A Third Set: Validation

Some workflows split the data **three** ways, not two.

- **Train**: where the model learns
- **Validation**: where you compare options and tune
- **Test**: the final score, looked at **once**

You **fit** to the train rows, and you **tune** until validation looks good, so both flatter you by construction. Only the **test** rows can still come out badly, because you never touched them.

**The only useful test is one you might fail.**
