# Developer Resources

## Learning Platforms

| Resource | Description |
|----------|-------------|
| [freeCodeCamp](https://www.freecodecamp.org/) | Free, structured curriculum covering web dev, Python, DSA, and more — great starting point |
| [The Odin Project](https://www.theodinproject.com/) | Full-stack curriculum (HTML → JS → Node → React) with real projects; fully free and project-driven |
| [CS50](https://cs50.harvard.edu/x/) | Harvard's intro to computer science — excellent for building a solid CS foundation from scratch |
| [roadmap.sh](https://roadmap.sh/) | Visual learning roadmaps for frontend, backend, DevOps, and more — helps you know what to learn next |
| [Codecademy](https://www.codecademy.com/) | Interactive, hands-on courses for beginners; good for syntax fundamentals |
