# Ionic Chat App (Ionic + React + RHF)

An **Ionic React** starter with **React Hook Form** installed — the starting
point for the "React Chat App with Ionic and RHF" coding demo. In class we build
it up into a chat app that handles input the clean way (**RHF + `reset()`**),
replacing the DOM-based approach.

- Stack: **Ionic + React + Capacitor**, plus **react-hook-form**
- Right now it's the blank Ionic starter — the chat is built live
- Compare with **`../react-chat-app`**, the plain-React version

## Run

```bash
yarn install
yarn dev        # or: ionic serve
```
