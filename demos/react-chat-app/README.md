# React Chat App (plain React)

A simple chat app built with **plain React** (Vite + TypeScript) — **no Ionic**,
no form library. It handles form input the **vanilla** way (`preventDefault` and
reading the value straight from the DOM), which is the "before" example we later
improve on.

- Stack: **React + Vite**, with `@faker-js/faker` for fake usernames
- See `src/App.tsx` for the input handling referenced in the June 30 deck
- Compare with **`../ionic-chat-app`**, the Ionic version of the same idea

## Run

```bash
yarn install
yarn dev
```
