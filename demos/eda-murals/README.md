# Data-Wrangling Demo: Mural Census

> **⚠️ FAKE DATA.** These CSVs were generated by an AI assistant (Claude) for
> educational purposes only. The murals, artists, neighborhoods, ratings, and
> dates are entirely invented — this is **not** real data.

A deliberately messy, two-table dataset for practicing **data wrangling** in
pandas, ending with a **merge**. It's a **code-along**: start your own notebook
and clean it up live.

## Files

- **`murals.csv`** (5,000 rows) — one row per mural: neighborhood, artist, medium, size, year
- **`condition_reports.csv`** (5,000 rows) — condition inspections: condition, rating, graffiti, fading

The two tables share an **`m_id`** key — merge them to pair each mural with its condition.

## Baked-in mess (every technique appears at least once)

- **Missing values** — blanks in several columns
- **Duplicates** — 100 repeated rows in each file
- **Wrong types** — `sz` is text (`"1,200"`), `dt` is an int date, `insp_dt` is a string date
- **Inconsistent formats** — neighborhoods, artists, condition, graffiti (casing / whitespace / abbreviations)
- **Outliers** — impossible sizes, years (1776), ratings (99), fading (150%)
- **Cryptic column names** — rename them
- **A column to bin** — mural size → small / medium / large
- **A merge** — `m_id` links the two tables (some ids match, some don't)
