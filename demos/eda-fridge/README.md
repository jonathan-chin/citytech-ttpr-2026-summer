# Data-Wrangling Demo: Community Fridge Census

> **⚠️ FAKE DATA.** These CSVs were generated by an AI assistant (Claude) for
> educational purposes only. The fridges, hosts, neighborhoods, temperatures, and
> dates are entirely invented — this is **not** real data.

A deliberately messy, two-table dataset for practicing **data wrangling** in
pandas, ending with a **merge**. It's a **code-along**: start your own notebook
and clean it up live.

## Files

- **`fridges.csv`** (5,000 rows) — one row per community fridge: neighborhood, host, capacity, power, install date
- **`stocking_log.csv`** (5,000 rows) — restock / condition checks: date, temperature, item count, cleanliness, restocked?

The two tables share an **`f_id`** key — merge them to pair each fridge with its logs.

## Baked-in mess (every technique appears at least once)

- **Missing values** — blanks in several columns
- **Duplicates** — 100 repeated rows in each file
- **Wrong types** — `cap` is text (`"1,200"`), `inst` is an int date, `log_dt` is a string date
- **Inconsistent formats** — neighborhoods, hosts, power source, cleanliness, restocked (casing / whitespace / abbreviations)
- **Outliers** — impossible capacities, temperatures, item counts, and install years (1776)
- **Cryptic column names** — rename them
- **A column to bin** — fridge capacity → small / medium / large
- **A merge** — `f_id` links the two tables (some ids match, some don't)
